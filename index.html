Data Clarity

"Data Clarity" es una aplicación web desarrollada con Python, Flask, Jinja, HTML y CSS. Permite a los usuarios cargar datos tabulares (en formatos como Excel, CSV o JSON) para obtener estadísticas básicas, una vista previa de los datos subidos y la posibilidad de generar gráficos personalizados seleccionando columnas específicas para su análisis.

Biblioteca Personal

Desarrollada con Python, Flask y Jinja, esta aplicación permite a los usuarios gestionar reseñas de libros mediante funcionalidades CRUD (crear, leer, actualizar y eliminar), conectada a una base de datos para persistencia de datos. Además, integra la API de Google Books para obtener información adicional sobre libros y enriquecer la experiencia del usuario. Utiliza HTML y CSS para la interfaz, ofreciendo un diseño intuitivo y funcional.
